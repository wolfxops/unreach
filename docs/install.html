Install

Up and running in one command.

Python 3.10+. No vendor SDKs. No API keys for scan, plan, workflow or triage — the model is optional everywhere.

  1. 1

    Install from source

    Editable install puts the unreach command on your PATH.

    git clone https://github.com/wolfxops/unreach.git
cd unreach
pip install -e ".[dev]"
  2. 2

    First win: the fixture scan

    Offline, deterministic, exit code 1 because high-confidence dead code exists.

    unreach scan --mock

    You should see pkg/orphan.py as an orphan_file block (0.92), dead_symbol as an unused_export block (0.88), and maybe_dead as a warn (0.58) because its module is imported whole.

  3. 3

    See the judge table

    Prosecution vs devil's advocate. The fixture's pkg/nightly.py is a cron job, not dead code.

    unreach judge --mock
  4. 4

    See the guided workflow

    Verify → edit → validate → remember steps, with judge and triage verdicts (heuristic when no key is set).

    unreach workflow --mock
  5. 5

    Scan your own repository

    Languages and frameworks are detected automatically. Memory is created at .unreach/memory.json; add it to .gitignore or commit it to share decisions.

    cd ~/code/your-service
unreach scan --format md
unreach scan --format sarif > unreach.sarif
  6. 6

    Connect your agent

    One stdio MCP server for Claude Code, Cursor and Codex.

    unreach mcp

    Tools: unreach.scan, unreach.judge, unreach.workflow, unreach.triage, unreach.plan, unreach.explain, unreach.remember, unreach.memory, unreach.languages. Plugins show a markdown table. See Plugins.

Optional: enable the model

Only explain and triage ever call a model, over plain OpenAI-compatible HTTP.

export UNREACH_API_KEY=...          # or OPENAI_API_KEY
export UNREACH_BASE_URL=https://api.openai.com   # any OpenAI-compatible endpoint
export UNREACH_MODEL=gpt-4o-mini    # optional
unreach triage                      # one batched call for warn findings; verdicts cached

Budget guarantee. Block and note findings are never sent. Warn findings are sent once, at most --max-items (default 8) per run, as evidence packets without file bodies. Unchanged findings are never re-asked.

GitHub Action

- uses: wolfxops/unreach@main
  with:
    path: .
    format: sarif

Use unreach scan --only-new in CI to fail only on new high-confidence dead code while a legacy backlog is worked down.
