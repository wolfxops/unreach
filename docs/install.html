Unreach
Install CLI Plugins

Install

Python 3.10+. No vendor SDKs. No API keys for scan or plan.

From source

git clone https://github.com/wolfxops/unreach.git
cd unreach
pip install -e ".[dev]"
unreach scan --mock
pytest -q

First win

On the fixture repo:

unreach scan fixtures/deadapp --mock

You should see pkg/orphan.py as an orphan_file block and dead_symbol as an unused_export block. Exit code 1 means high-confidence dead code was found.

MCP

unreach mcp

Stdio JSON-RPC. Tools: unreach.scan, unreach.explain, unreach.plan.

GitHub Action

- uses: wolfxops/unreach@main
  with:
    path: .
    format: json
