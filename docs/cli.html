CLI

unreach scan [PATH] [--mock] [--format json|md|sarif] [--lang auto|py|ts]
                   [--only-new] [--compact] [--min-confidence 0.25] [--no-memory]
unreach plan [PATH] [--mock] [--format json|md]
unreach workflow [PATH] [--format json|md] [--max 12]
unreach explain FINDING_ID [PATH]
unreach remember FINDING_ID --decision keep|false_positive|resolved [--note ...] [--path PATH]
unreach memory [PATH] [--clear] [--forget FINDING_ID]
unreach mcp
FlagEffect
--format sarifSARIF 2.1.0 for GitHub code scanning; confidence and signals in properties.
--only-newShow only findings not present in memory; exit 1 only for new block findings (CI ratchet).
--compactJSON: full evidence for new findings, one-liners for persisting ones, plus tokens_saved_estimate.
--min-confidenceDrop findings below the threshold (default 0.25).
--no-memoryStateless run; do not read or write .unreach/memory.json.

Exit codes

  • 0 — no high-confidence (block) dead code
  • 1 — one or more block findings
  • 2 — tool error

Finding schema

Finding(
  id: str,
  kind: str,          # unused_export | orphan_file | unused_dep | unreachable
  severity: str,      # block | warn | note
  path: str,
  symbol: str | None,
  why: str,
  evidence: list[str],
  confidence: float,        # 0..1, deterministic
  signals: dict[str, float] # named adjustments that produced the score
)

Severity is derived from confidence: block ≥ 0.85, warn ≥ 0.55, else note. See Confidence. Python is first-class; the TypeScript import graph is best-effort and never reaches block for exports.

Plan

unreach plan and MCP unreach.plan return an ordered list. Unreach never deletes files and never writes a patch in v0.

Explain

Optional OpenAI-compatible HTTP if UNREACH_API_KEY or OPENAI_API_KEY is set. Otherwise a heuristic paragraph. No vendor SDKs.
