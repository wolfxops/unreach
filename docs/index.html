Unreach

Find the code your agents keep rewriting around.

Dead-code scan for Claude, Cursor, and Codex.

Install

pip install -e .
unreach scan --mock

`--mock` needs no API keys. The scan is deterministic. The model is optional and only used for unreach explain.

Built around the pain points

Confidence score

Every finding carries a deterministic confidence and named signals. Framework decorators, dynamic imports, string-named modules and config references lower it. Only ≥ 0.85 becomes block.

Agentic workflow

unreach.workflow emits verify → edit → validate → remember steps tuned to the detected languages and frameworks: exact files to read, grep targets, pytest/tsc/mypy commands.

Long-term memory

.unreach/memory.json caches parsed facts by content hash and remembers findings and decisions. Next session: one-liners for known findings, nothing for acknowledged ones, fewer tokens.

Codex

command = "unreach"
args = ["mcp"]

Add that block to ~/.codex/config.toml. Same stdio server, same findings.

One engine

One analyzer. Three manifests. Auto-delete is forbidden. unreach.plan returns an ordered list only.
