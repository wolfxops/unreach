Unreach

Find the code your agents keep rewriting around.

Dead-code scan for Claude, Cursor, and Codex.

Install

pip install -e .
unreach scan --mock

`--mock` needs no API keys. The scan is deterministic. The model is optional and only used for unreach explain.

Plugins

Claude Code

/plugin marketplace add wolfxops/unreach
/plugin install unreach

When you ask about dead or unused code, the skill calls MCP unreach.scan then unreach.plan.

Cursor

{
  "mcpServers": {
    "unreach": {
      "command": "unreach",
      "args": ["mcp"]
    }
  }
}

Do not guess unused code. Point Cursor at unreach mcp and the plugin skill/rule.

Codex

[mcp_servers.unreach]
command = "unreach"
args = ["mcp"]

Add that block to ~/.codex/config.toml. Same stdio server, same findings.

One engine

One analyzer. Three manifests. Auto-delete is forbidden. unreach.plan returns an ordered list only.
