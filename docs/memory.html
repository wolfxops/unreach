Long-term memory

Unreach remembers what it already told you. .unreach/memory.json lives next to the scanned root and makes the next iteration cheaper in parse time and in tokens.

What is stored

SectionContentsEffect
filesPer file: SHA-256 of content and extracted facts (exports, imports, decorators, bases, string literals). Never the source itself.Unchanged files are not re-parsed. cache_hits / cache_misses are reported on every run.
findingsPer finding id: first_seen, last_seen, seen_count, last confidence, status open/resolved.Delta per run: new, persisting, resolved. stable_across_runs nudges confidence.
decisionsPer finding id: keep | false_positive | resolved, note, timestamp.keep and false_positive suppress the finding from output and the plan. Auto-flipped to resolved when the finding disappears.
runsLast 50 runs: totals, delta counts, cache stats.Trend line for the team; ratchet evidence in CI.
profileLast detected language/framework profile.Lets an agent answer "what kind of repo is this" without a re-scan.

How it cuts token consumption

  1. Compact packets by default. MCP unreach.scan returns full evidence only for new findings. Findings already seen come back as persisting_brief one-liners (id, severity, confidence). The response includes tokens_saved_estimate.
  2. Acknowledged findings vanish. After unreach.remember with keep or false_positive, the finding is omitted; only a suppressed id list remains.
  3. Workflow names exact files. Steps carry read and grep targets so the agent does bounded reads instead of crawling.
  4. Only-new mode. unreach scan --only-new (or only_new: true) prints just the delta and fails only on new block findings.
# first session: 2 findings, full evidence
$ unreach scan . --format json --compact | jq .delta.counts
{ "new": 2, "persisting": 0, "resolved": 0, "suppressed": 0 }

# agent triages one as intentional public API
$ unreach remember unused_export:pkg/exports.py:dead_symbol --decision keep --note "plugin API"

# next session: nothing new, one-liners only, one suppressed
$ unreach scan . --format json --compact | jq '.delta.counts, .tokens_saved_estimate'
{ "new": 0, "persisting": 1, "resolved": 0, "suppressed": 1 }

Commands and tools

unreach memory [PATH]                     # summary + decisions
unreach memory [PATH] --clear             # delete .unreach/memory.json
unreach memory [PATH] --forget FINDING_ID # drop one decision
unreach remember FINDING_ID --decision keep|false_positive|resolved [--note ...] [--path PATH]
unreach scan --no-memory                  # stateless run

MCP: unreach.memory { path?, clear? }
MCP: unreach.remember { id, decision, note?, path? }
MCP: unreach.scan { only_new?, full?, memory? }

Team usage

  • Local only: add .unreach/ to .gitignore (the default in this repo).
  • Shared baseline / ratchet: commit .unreach/memory.json. CI runs unreach scan --only-new; decisions with notes become the audit trail.
  • Custom location: set UNREACH_MEMORY_DIR.

Memory never contains source code or secrets: only hashes, symbol names, paths, and your notes. Deleting the file is always safe; the next scan rebuilds it.
