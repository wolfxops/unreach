Plugins

Thin wrappers around one stdio MCP server. Same engine. No second scanner.

Every skill tells the agent the same loop: unreach.scan → unreach.workflow → follow the steps → unreach.remember. Do not guess unused code; do not delete without approval.

Claude Code

Manifest: plugins/claude/.claude-plugin/plugin.json. Skill tells the agent to call unreach.scan then unreach.plan.

/plugin marketplace add wolfxops/unreach
/plugin install unreach

Cursor

Manifest: plugins/cursor/.cursor-plugin/plugin.json. Rule: do not guess unused code; call the MCP.

{
  "mcpServers": {
    "unreach": {
      "command": "unreach",
      "args": ["mcp"]
    }
  }
}

Codex

See plugins/codex/README.md. Stdio command:

unreach mcp
[mcp_servers.unreach]
command = "unreach"
args = ["mcp"]

Place that in ~/.codex/config.toml.

MCP tools

ToolInputOutput
unreach.scan{ path?, only_new?, full?, min_confidence?, memory? }findings JSON with confidence; compact packet by default
unreach.explain{ id: string }paragraph
unreach.plan{ path? }ordered steps ranked by confidence, no writes
unreach.workflow{ path?, max_findings? }language-aware verify/edit/validate/remember steps
unreach.remember{ id, decision, note?, path? }stores keep / false_positive / resolved in memory
unreach.memory{ path?, clear? }runs, cache stats, open findings, decisions
